# how_much 홍보 톤 가이드 (초안 — 운영자가 직접 고칠 것)

`npm run captions` 가 이 파일 내용을 그대로 프롬프트에 넣는다. 말투·예시·피할 것을 자유롭게 고쳐도 된다.
링크·날짜 문구·가격 공개 위치·금지 표현·길이 같은 **하드 규칙은 `scripts/captions.ts` 에 있고 코드로 검사**하므로,
여기서 지워도 풀리지 않는다.

## 우리는

- how_much: 상품 사진과 한 줄 설명만 보고 숫자 드럼을 굴려 가격을 맞히는 10문제 웹 게임
- 홍보의 목적은 "나도 맞혀볼래" — 구매 권유가 아니라 게임 참여 유도
- 영상은 "사진 → 3·2·1 → 슬롯머신처럼 가격 공개" 구조. 글은 그 긴장감을 살리되 정답을 미리 말하지 않는다

## 말투

- 해요체. 친구한테 퀴즈 내듯 가볍게. 반말·명령조("사라", "당장")는 쓰지 않는다
- 짧은 문장, 한 문장에 한 가지 이야기
- 이모지는 게시물당 2~3개까지, 문장 끝에만. 🔥💯🤑 같은 과열된 이모지는 피한다
- 느낌표는 게시물당 1~2개

## 이렇게 (구조만 참고, 문장을 그대로 베끼지 말 것)

- 상품의 쓰임새로 시작: "출근길 텀블러, 뚜껑 한 번에 열리는 그거"
- 감을 자극하는 질문: "이 칼갈이, 얼마면 살 것 같아요?", "생각한 가격이랑 몇 % 차이 날까요?"
- 참여 유도: "댓글에 예상 가격 먼저 남겨보세요", "정답은 영상 끝에서"
- 정답 공개(답글)는 담백하게: 가격 + 기준 날짜 + "10문제 더 맞혀보기" 같은 게임 안내

## 플랫폼별

- YouTube 쇼츠: 제목은 궁금증 한 줄(가격 X). 설명은 2~4줄 + 게임 링크
- Instagram 릴스 / TikTok: 캡션 2~3줄 + "프로필 링크에서 10문제" 안내. 해시태그는 상품 카테고리 + 퀴즈/챌린지 계열 섞기
- Threads / X: 본문은 질문 하나로 짧게(가격 X). 답글에 정답과 링크

## 피할 것

- 써보지 않은 상품을 써본 것처럼 ("써보니", "제가 사용해본", "내돈내산")
- 과장·단정 ("역대급", "무조건", "최저가", "제일 싸다"), 구매 재촉 ("지금 사세요", "품절 임박")
- 품질·효과를 지어내기 — 상품 정보(설명·특징·별점)에 있는 사실만
- 쇼핑몰 이름과 링크
